# Calculadora de Producción de Leche

Aplicación web desarrollada con Flask que permite calcular la producción diaria de leche y la ganancia obtenida según los datos ingresados por el usuario.

## Datos solicitados

- Cantidad de vacas
- Litros que produce cada vaca
- Precio por litro de leche
- Gastos diarios por vaca

## Tecnologías utilizadas

- Python
- Flask

## Instalación

1. Instalar las dependencias:

pip install -r requirements.txt

2. Ejecutar la aplicación:

python app.py

3. Abrir en el navegador:

http://127.0.0.1:5000
